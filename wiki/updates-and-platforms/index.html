Updates and Platforms

The game is one file. Every platform runs the same build and updates itself.

Android

Install once from the rolling release:

AscentToTheStars.apk

After that, updates are automatic. The app checks on launch and resume, downloads in the background, and offers the installer when ready. Content-only updates can also apply silently in place. Your save survives every update.

Windows

AscentToTheStars-Setup.exe (an .msi is on the same release). The install is small because it uses the OS webview instead of a bundled browser. On launch it pulls the latest game from the release mirror and falls back to its bundled copy offline. You essentially never need to reinstall.

Browser

Download index.html and open it, or host it anywhere static. The page checks for updates on its own and offers a reload when one lands.

Saves

Saves live on the device (browser storage, or the app's private storage), with 5 slots plus the cross-life Soul. Browsers keep saves per web address, so the game at a different address starts empty.

Cloud Saves (Config tab) keep your slots in step across the browser, Android and Windows. Press Create a sync code on one device, then Use this code with the same code on the others. There is no account and nothing personal is stored; anyone with the code can change your cloud saves, so keep it private. Your settings (music, volume, toggles) stay on each device.

  • Syncing happens when the game opens, every few minutes, and when you leave it. Sync now forces one.
  • If the same slot was played on two devices since they last synced, the game asks which one to keep. It never overwrites one with the other on its own.
  • Delete my cloud saves erases everything stored under the code, and the code itself.

Without the cloud, the Config tab still exports a save as text or a file (Cultivator Snapshot) for Load / Transfer a Save on another device.

If an update seems stuck

Give it an hour. The app package build can trail a content release briefly. The Config tab's Check for Updates Now button forces a check and reports plainly what happened.
